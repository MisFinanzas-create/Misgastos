# 💰 Expense Tracker

A modern, fully-featured expense tracking web application built with vanilla HTML, CSS, and JavaScript. Manage your income and expenses efficiently with a responsive, user-friendly interface.

## 🌟 Features

- ✅ **Add Transactions** - Easily add income and expense transactions
- 💰 **Income & Expense Tracking** - Track both income and expenses separately
- 🗑️ **Delete Transactions** - Remove individual transactions with confirmation
- 📊 **Real-time Balance** - View your current balance, income, and expenses instantly
- 🔍 **Filter Transactions** - Filter by All, Income, or Expenses
- 💾 **LocalStorage** - All data is automatically saved to browser LocalStorage
- 📅 **Date Selection** - Add date to each transaction
- 🏷️ **Categories** - Organize transactions with predefined categories:
  - Income: Salary, Freelance, Investment, Other Income
  - Expenses: Food, Transportation, Utilities, Entertainment, Shopping, Healthcare, Education, Other
- 📱 **Fully Responsive** - Works seamlessly on desktop, tablet, and mobile devices
- 🎨 **Modern UI Design** - Beautiful gradient design with smooth animations
- ⚡ **Fast & Lightweight** - No dependencies, pure vanilla JavaScript
- 🌙 **Dark Mode Support** - Automatically adapts to system dark mode preference
- 📖 **Well-Commented Code** - Easy to understand and modify
